# BSRF-HEPS 语料库规模描述

本研究构建的 BSRF-HEPS 键值型语料库共包含 550 条完整 K-V 语料记录。其中包含 472 个唯一 key、480 个唯一 value 和 547 个唯一 K-V 对；完全重复的 K-V 记录为3条，约占全部记录的0.55%。此外，有25个 key 对应多个不同 value，说明该语料库包含一对多的知识组织形式，不能仅使用唯一 key 数表示其实际检索规模。

在文本规模方面，K 列共包含 12,305 个字符，V 列共包含 56,423 个字符，二者合计为 68,728 个字符；去除空白字符后为 65,553 个字符。每条 K-V 记录平均包含 124.96 个字符，中位数为45个字符；K 长度范围为8-63个字符，V长度范围为2-2,969个字符，表明语料同时包含简短属性值和较长的实验操作文本。

语料中包含 44,451 个中文字符、3,202 个英文词单元，其中英文词单元由K列的879个和V列的2,323个组成。排除13条“[图片占位]”和10条“——”后，共保留527条实质性文本记录，占完整记录的95.82%；对应的K-V文本合计为68,013个字符。论文中建议以“550条完整K-V记录”为原始语料规模，以“547条唯一K-V对”和“527条实质性文本记录”作为补充规模指标。
